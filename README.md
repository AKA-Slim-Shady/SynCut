# SynCut - RealTime Collaborative Video Editor

## How to get started?

1. **Download the latest version of SynCut from GitHub:**
   ```bash
   git clone https://github.com/AKA-Slim-Shady/SynCut.git
   cd Real-Time Video Editor
   ```

2. **Give the start script access to run docker code**
   ```bash
   chmod +x start.sh
   ```

3. **Enjoy the Application!**
  ```bash
  ./start.sh
  ```

4. **Gracefully stop the container**
  ```bash
  docker-compose down
  ```
